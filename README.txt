ALOKA MULTY SYSTEM — DARAZ-STYLE SHOP
======================================
Files:
- index.html
- style.css
- script.js
- assets/ (logo + product photos)

HOW TO USE
1. Extract the ZIP.
2. Double-click index.html to open the shop.
3. To publish online, upload the whole folder to any static host.

HOW IT WORKS
- Flash Sale row with live countdown (resets daily).
- Category pills: Wardrobes / Cupboards / Drawers / Shoe / Custom.
- Live search box filters products instantly.
- "Buy Now" opens WhatsApp with a ready-made order message.
- Cart drawer: add items, change quantity, then "Checkout via WhatsApp"
  sends the full order list with the subtotal to 075 353 4777.

EDIT PRODUCTS
Open script.js and edit the PRODUCTS list at the top
(name, price, old price, rating, photo). Save and refresh.

NOTE
Some product photos are stock-style images used as placeholders.
Replace any photo inside assets/ with your own real product photo
(keep the same file name) before publishing.
